OpenLR vs. linestring map matching

Click the map to add route points. Where roads are stacked, pick the road you mean – its FRC (road class) is stored with the point and decides which level the route takes.

Route points

Format and FRC values

One point per line: lat, lon, FRC. The FRC is optional (nearest road). Pairs in lon,lat order and Mapbox-style lon,lat;lon,lat lists are recognised too.

Map A → OSM difference

OpenLR is encoded on map A and decoded on OSM; the linestring methods get map A's coordinates.
